# Episode 2: Secrets in prompts

**Video:** [2 Million AI Prompts Had Bait Keys. Attackers Tried Them Within Hours](https://www.youtube.com/watch?v=vP8fQgB0So4)

The tool for this episode, **prompt-secret-guard**, lives in its own repository:
👉 https://github.com/mgmehdiforme/prompt-secret-guard

```bash
/plugin marketplace add mgmehdiforme/prompt-secret-guard
/plugin install prompt-secret-guard@prompt-secret-guard
```

It stops your AI coding agent from reading `.env` and credential files, blocks API keys pasted into prompts, and audits your app against the 7-point checklist.

Checklist: https://gist.github.com/mgmehdiforme/6be862e6f9e043d623890922c3ff5e29
